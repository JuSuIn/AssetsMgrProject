# 📘 StockHistory API 명세서

## 1. 설명
종목의 과거 주가 데이터를 저장하고 조회하는 API입니다.  
이 데이터는 차트, 백테스트, 리포트 생성 등에 사용되며, 보통 비동기 수집 프로세스와 연결됩니다.

---

## 2. 필드 구조

| 필드명     | 타입     | 설명                    |
|------------|----------|-------------------------|
| id         | integer  | 고유 ID                 |
| stock_info | integer  | 종목 ID (FK: StockInfo) |
| date       | date     | 거래일자 (YYYY-MM-DD)   |
| open       | float    | 시가                    |
| close      | float    | 종가                    |
| high       | float    | 고가                    |
| low        | float    | 저가                    |
| volume     | integer  | 거래량                  |

---

## 3. 기능별 API 명세

### 🔹 과거 데이터 등록 (비동기 수집용)

- **POST** `/api/stockhistory/`

```json
{
  "stock_info": 1,
  "date": "2024-07-01",
  "open": 70000,
  "close": 71200,
  "high": 71500,
  "low": 69800,
  "volume": 1300000
}
```

---

### 🔹 특정 종목의 기간별 과거 데이터 조회

- **GET** `/api/stockhistory/?ticker=005930&start=2024-07-01&end=2024-07-31`

```json
[
  {
    "date": "2024-07-01",
    "open": 70000,
    "close": 71200,
    "high": 71500,
    "low": 69800,
    "volume": 1300000
  },
  {
    "date": "2024-07-02",
    "open": 71200,
    "close": 70800,
    "high": 71300,
    "low": 70700,
    "volume": 900000
  }
]
```

#### 🔍 Query Parameters

| 이름   | 설명              | 예시 값         |
|--------|-------------------|------------------|
| ticker | 종목 코드          | `005930`        |
| start  | 시작 날짜 (YYYY-MM-DD) | `2024-07-01` |
| end    | 종료 날짜 (YYYY-MM-DD) | `2024-07-31` |

---

### 🔹 단일 일자 데이터 조회

- **GET** `/api/stockhistory/day/?ticker=005930&date=2024-07-01`

```json
{
  "date": "2024-07-01",
  "open": 70000,
  "close": 71200,
  "high": 71500,
  "low": 69800,
  "volume": 1300000
}
```

---

### 🔹 중복 등록 방지 (선택적)

- 기존 데이터가 있을 경우 `PUT`으로 갱신 또는 무시 로직 적용
